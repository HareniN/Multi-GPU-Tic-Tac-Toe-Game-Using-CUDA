# Multi-GPU-Tic-Tac-Toe-Game-Using-CUDA
This project is a CUDA-based Tic-Tac-Toe game where two GPU competitors play against each other automatically. GPU 0 plays as X and GPU 1 plays as O. CUDA kernels are used to analyze the board and select moves in parallel. The program demonstrates GPU programming concepts such as kernel execution, memory transfer, and turn-based game simulation.
